03

Permission denial stays useful

Keep cached inbox reading and refresh available. Explain notification settings; never show Ready until the server confirms registration.

Every Android screen, mapped.

The hard moments deserve a design.

A beautiful inbox is only useful when account, network and permission changes are handled carefully.

Notification opens after logout

Ask for sign-in, preserve the intended destination, then recheck workspace access. Never reveal event data in a public route.

The phone is offline

Show cached content and a last-updated time. Do not announce a shared acknowledgement until the server confirms it.

Permission is disabled

Keep the inbox available. Offer an explicit settings recovery action; do not repeatedly trigger permission requests.

Someone else acknowledged

Replace the action with the acknowledging person and time. Repeated calls return the same shared record.
