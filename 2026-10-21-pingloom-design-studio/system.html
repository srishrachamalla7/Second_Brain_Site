06 / Design system

A recognizable voice.
A dependable system.

Use shared semantic tokens and component rules across the product. Adapt the implementation to each platform, rather than copying web pixels onto a phone.

Reusable components.

These are the shared design contracts. A status badge is never the only way a user learns what happened.

01

Event row

Project and channel, event title, timestamp, text priority, personal read state and shared acknowledgement. Stable pagination and accessible labels.

02

Credential reveal

One-time demonstration in setup, visible copy feedback, a clear server-only explanation, and revocation confirmation. Never reveal old keys.

03

State panel

Name the problem, retain useful context, show one recovery action and preserve form input. Avoid empty pages and indefinite spinners.

An accessible experience is complete.

Browser checks support this design review. Real native accessibility checks remain part of implementation.

Focus & keyboard

Visible focus, logical reading order, properly labelled controls, native disclosures and no hover-only actions. Return users to the right location after sheets close.

Motion & transparency

Honor reduced motion, offer opaque material fallbacks, and avoid movement that competes with the alert content. Use restrained feedback for state changes.

Text & touch

Support zoom and large text, wrap long project names and event titles, respect safe areas, and provide visible alternatives to swipe actions.

Errors & recovery

Associate field errors with inputs and focus a linked error summary for multi-error forms. Preserve safe entered data across recoverable failures.
