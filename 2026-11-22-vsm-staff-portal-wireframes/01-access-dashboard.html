01-01

Sign in

Face ID (a passkey stored on the phone) is the main way in. The password form is the fallback and the only way for the very first sign-in.

  • Sign in with Face ID: the iPhone asks for Face ID, then opens Home (01-04). On Android it is the fingerprint prompt.
  • Sign in with the password: on the first sign-in from this phone it goes to 01-02 (set up Face ID); after that, straight to Home.
  • Eye button shows the password. No "create account": the Owner creates users (01-08).

01-01b

Sign in: error states

Both failure types on one screen for review. In the app only the one that happened shows.

  • Face ID failed or was cancelled: a banner above the button, with "Try Face ID again". The password form stays open.
  • Wrong password: the message sits under the field and says how many tries are left. It never says which of the two was wrong.
  • After 5 wrong tries the form locks for 15 minutes and the Owner sees a row in the audit log (01-09).
Proposal: 5 tries, 15-minute lock. Owner to confirm.

01-03

Install on your iPhone (helper)

iOS has no install button, so the app explains the 3 Safari steps. It sits just above Safari's bottom bar, where the Share button is.

  • Shown only in mobile Safari, only when the app is not already running from the Home Screen, and at most once per phone after sign-in.
  • Got it closes it; it can come back once a week. Don't show again stops it. It is always reachable from More › "Install on this phone".
  • On Android Chrome the browser's own "Install app" prompt is used instead.
Alerts (push notifications) need iOS 16.4+ and the app on the Home Screen. Do we want alerts at all, or is the Home inbox enough?

01-04

Home dashboard (top)

Answers "what must I fix today?" first. The figures come from the last biometric upload, so the card is labelled with that day, not "today".

  • Upload row: when the file was last uploaded and which dates it covers. "Upload" opens the import in Attendance (03). Turns amber after 3 days.

  • Needs attention rows open the matching Attendance list (fix punches, assign codes, short-day review).
  • Inbox (top right) opens 01-05 with every open item. More opens the sheet (01-06). Try it.
Design question: "today's" counts need the device data the same day. With a monthly file upload, Home can only show the last uploaded day. Can the store upload daily, or should we look at a direct link to the device later?

01-08b

Users & roles: permission matrix

Three fixed roles. A tick means the role can save that kind of change; a dash means view only.

  • Everyone can see every screen; the matrix only controls who can save a change.
  • Roles are fixed (no custom roles) to keep it simple for 3–4 users.
  • When someone without the right taps a change button, it is shown disabled with "Ask the Owner".
Proposed defaults for question 12, not decided: only the Owner changes salary; the Supervisor overrides attendance and swaps; the Accountant handles payouts, advances and payslips. Should the Owner be able to tick boxes per role?
