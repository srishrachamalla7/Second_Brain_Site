Atlas frame 0-8 (push shade, heads-up, in-app banners) are OS notification mockups, not app screens, so they are not compared. Atlas frames are in their own theme (light or dark); app shots are paired by screen, theme noted in the file name.

Pass 3 (23 Oct 2026): typography root cause

  • The font files were registered correctly (expo-font config plugin writes per-weight font-family XML; MainApplication registers Geist, Geist Mono and Bricolage Grotesque; verified in the APK).
  • What did not match: native-stack header titles and bottom-navigation labels had no fontFamily, so Android drew them in Roboto; screen, sheet, dialog and page titles used Geist where every atlas Android frame uses Bricolage Grotesque; Geist 700 was requested although only 400/500/600 ship (Android fell back to 600); sizes followed the Material table (body 16, row titles 16, chips 15) rather than the atlas frames (body 15, rows 15, row text 13, chips 13, pills 11, app bar 20).
  • Also found: Metro started with CI=1 runs without file watching, so edits did not reach the emulator until Metro was restarted; earlier comparison shots may have shown stale code.
  • Fix: one Android type scale in src/theme/typography.ts taken from the atlas frames (Bricolage for display/title/section, Geist for UI, Geist Mono for mono; only shipped weights, enforced by a test), Bricolage 20/600 stack header titles and Geist 12/500 tab labels via src/theme/navigation.ts, Geist 12/600 uppercase eyebrows, 52dp primary buttons and fields.
  • Scale fix: the atlas draws Android phones 302 px wide for a 412 dp screen, so frame px must be multiplied by 412/302 (about 1.364). The first pass of this round copied frame px 1:1, about 27% too small. Now src/theme/atlas.ts (atlasPx / atlasDp) converts every frame-derived size: the type scale (body 20, row text 18, caption and mono 16, section and app-bar 27, title 30, display 35), paddings, radii, control heights (52 px buttons and fields = 71 dp), chips, pills, icons (18 px = 25 dp) and switches. Exception: the bottom-navigation label stays at 14 sp because the Material 3 bar has a fixed 80 dp height and clips at 16. Frames 25, 33, 34 and 52 still show the pre-scale shots.
