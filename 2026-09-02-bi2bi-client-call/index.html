Part 2 — The 15 change requests

Listed in the order the client raised them, which they said was their priority order.

1. Discount needs a lock — a new POS-only role

The problem. Anyone standing at the counter can key in a direct discount. There is no approval, no ceiling, and no edit afterwards.

Three options were weighed:

OptionVerdict
Authenticator-style rotating code, shared verballyWorkable, but a code that lives for a minute can be used four or five times
Login-and-approve before every invoiceRejected — 15 bills in an hour means 15 approvals. Too heavy.
A restricted role, plus the existing activity logChosen

The decision. Admin Management currently offers only one role. Create a second.

   ┌───────────────────────┐        ┌───────────────────────┐
   │        ADMIN          │        │      POS USER         │
   │                       │        │      (new)            │

   The activity log already records who gave which discount.
   A per-role discount ceiling sits on top of that.

To do: create the POS User role, hide everything except Counter Sales from it, and add a discount threshold per role.

6. Geo-tagging is 5–6 km off

Staff stood inside the shop and pinned the location. The record reads Bhagyalakshmi Colony Road. Pressing View on map opens Balanagar, five to six kilometres away. Reproduced on two different phones.

Likely cause. To avoid the paid Google Maps API we are using OpenStreetMap, whose India coverage is thinner. That normally costs a few hundred metres of accuracy — not five kilometres. So the real suspect is a naming or ordering mismatch in the latitude/longitude handling, not the map data.

Why it matters commercially. Right now one person — the marketing staffer doing the onboarding — knows where every kirana shop physically is. He is supporting deliveries for about fifteen more days. The next delivery hire will know nothing, and will have only the map pin to work from.

To do: verify the lat/long values end to end and test from a real distributor login. The client offered a phone number to log in with.
